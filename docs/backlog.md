## BL-001 CLI 国际化

背景：当前 CLI 统一使用中文。未来面向其他语言的用户时，需要明确的语言选择方式。

范围：规划语言选择和回退规则，集中管理帮助、参数错误、运行错误、日志和结果文案。
默认语言保持中文；是否新增选项或环境变量，在实施前确定。

验收：中文仍为默认；至少一种其他语言可显式选择；各语言下命令、选项、JSON 字段、
枚举值、退出码和输入输出约定一致。帮助、schema 描述及错误提示使用所选语言，
缺失翻译有确定的回退规则，并有回归测试。
